# Resources

> High signal, not volume. Each guide is sourced, dated, and re-checked against the
> ecosystem as it moves - not a list of links left to rot.

These guides start from one angle: **operational governance for builders** who use Claude
Code day to day. They're free, vendor-neutral, and meant to be useful whether or not you
ever touch our product. Each one carries the Claude Code version it was last revalidated
against, and is kept in sync with our [weekly watch](../watch/).

## Guides

- **Treat a cloned repo's Claude Code setup as untrusted code** - [EN](guides/untrusted-repo-config.en.md) · [FR](guides/untrusted-repo-config.fr.md)
  - when you open someone else's project, its hidden config can run on your machine. The
  durable reflex, what a trust decision actually covers, and a free manual checklist.
  _Last revalidated: 2026-09-10 · Claude Code v2.1.267_
- **Harden your own Claude Code permissions: go deny-by-default** - [EN](guides/harden-claude-code-permissions.en.md) · [FR](guides/harden-claude-code-permissions.fr.md)
  - as you spread Claude Code across more projects, its permissions drift toward "allow." Flip to
  deny-by-default, and learn what your rule patterns actually match. _Last revalidated: 2026-09-10 · Claude Code v2.1.267_

Every guide ships in English and French, like the [weekly watch](../watch/).
More guides will land as the ecosystem gives us something genuinely worth writing about.
